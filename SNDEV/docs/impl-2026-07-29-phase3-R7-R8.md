- `tests/test_oq_llm_provider_config.py` (new)
  - Unit test (no network) asserting `_resolve_openrouter_key()` honors env and secret-file injection, and that an unset key resolves to `None`.
- `tests/test_oq_llm_ollama_integration.py` (new, gated `@pytest.mark.ollama`/`integration`/`external`)
  - Skipped unless `BIOSYNC_OLLAMA_INTEGRATION=1`. Sets `LLM_PROVIDER=ollama` (+ base URL/model), reloads the gateway module, asserts `get_provider_config()['provider']=='ollama'`, performs a real `generate_text()` call, and asserts the output is non-empty and is NOT the `[SIMULATED LLM OUTPUT ...]` mock marker. Pre-checks Ollama reachability (`/api/tags`) and skips when the server is down.
- `tests/conftest.py`
  - Registered the `ollama` marker.

### R8 — files changed
- `SNDEV/scripts/pq4_24h_ingest.py` (new, agent script)
  - Canonical, importable `run_soak(db_url, duration_s, workers)` + CLI (`--db-url`, `--seconds`, `--workers`). Creates a dedicated `pq4_soak` table, runs N worker threads doing sustained concurrent INSERTs for `duration_s`, catches `DeadlockDetected` (count), probes lock contention via `pg_locks`, and reports `{rows_inserted, deadlocks, errors, memory_growth_pct, ...}` using a cross-platform peak-RSS reader (`resource` on POSIX, `psutil` fallback on Windows).
- `tests/performance/test_pq4_ingest_soak.py` (new, gated `@pytest.mark.pq4`/`performance`/`slow`/`db`)
  - Skipped unless `BIOSYNC_PQ4_DATABASE_URL` is set. Imports `run_soak` from `SNDEV/scripts`, runs for `BIOSYNC_PQ4_SOAK_SECONDS` (default **86400 = 24 h** to match SRS; CI overrides to a shorter value), asserts **deadlocks == 0** and **memory_growth_pct <= 5.0**.
- `tests/performance/test_pq1_locust_run.py` (new, gated `@pytest.mark.pq1`/`performance`)
  - Skipped unless `BIOSYNC_PQ1_BASE_URL` is set. Lazily imports `locust`, builds an `Environment(user_classes=[TelemetryIngestUser], host=BASE_URL)`, runs a headless `LocalRunner` for `BIOSYNC_PQ1_DURATION` s (default 60) with `BIOSYNC_PQ1_USERS` (default 10), then asserts SLOs: total requests > 0, failure ratio < 0.01, P95 < 250 ms.
- `tests/performance/test_pq3_1m_rows.py`
  - Added an explicit `SELECT count(*)` assertion that exactly 1,000,000 rows were loaded (proves it is a *real* 1M-row run, not an extrapolation), and documented the CI wiring in `pq.yml`.
- `.github/workflows/pq.yml`
  - Added `pq4` to the dispatch choice matrix and a `pq4-soak` job (dispatch-only, not nightly) that starts the stack and runs the PQ-4 pytest with `BIOSYNC_PQ4_DATABASE_URL` (mutual-TLS client cert from secrets) and a `soak_seconds` input.
  - Added a `pq1-locust` job (dispatch-only) installing `locust` and running `test_pq1_locust_run.py` against the started stack (requires `PQ_API_TOKEN` secret).
- `middleware/requirements.txt`
  - Pinned `locust==2.46.2` (test dependency for the promoted PQ-1 run).
