## Specification Summary (SRS FR-3.15)
- FR-3.15.1 Provider Abstraction (C8): OpenAI-compatible client, runtime switch OpenRouter ↔ Ollama/vLLM via config, no code change.
- FR-3.15.2 Async Isolation (C6): LLM calls dispatched via FastAPI BackgroundTasks, offloaded off the event loop (asyncio.to_thread).
- FR-3.15.3 RAG Repository (C9): local static markdown/JSON template corpus (CAP/CLIA, FDA, EHR rubrics) as RAG source; registry in `rag_templates`.
- FR-3.15.4 Pulse→Narrative: aggregate Pulse telemetry over window (default 60s), synthesize progress note via LLM.
- FR-3.15.5 ClinVar→Pathology Report: retrieve CAP/CLIA template, merge variant data into Molecular Pathology Summary Report.
- FR-3.15.6 Output Provenance: every artifact stored with provenance (model, provider, prompt hash, template id, source hash) in append-only `clinical_text_outputs` + `llm_runs`.
- FR-3.15.7 EHR Ingestion Harness: push generated text to downstream EHR/FHIR endpoint and validate critical signals preserved through text→structured mapping.
- Qualification: OQ-21, OQ-22, PQ-7.

### Key design decisions
- Default `LLM_PROVIDER=mock` (deterministic offline stub) so the gateway is runnable/qualifiable with zero network or secrets (C8 satisfied; mock is a valid selectable provider). Production sets `openrouter`/`ollama`/`vllm`.
- `openai` SDK lazy-imported only when a real provider is selected → module import-safe without the dependency installed.
- RAG retrieval is a dependency-free keyword/section overlap scorer appropriate for a *static* template corpus (C9).
- RAG seeding is insert-only (the `rag_templates` table is append-only / read-only after bulk load) so re-running the seed is idempotent and trigger-safe.
