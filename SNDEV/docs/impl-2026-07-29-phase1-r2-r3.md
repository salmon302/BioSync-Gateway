## Risk notes
- The db service now requires generated certs (`./nginx/generate-certs.sh`)
  or it fails fast. The middleware runs as the host UID (COMPOSE_UID/GID) so
  it can read the host-owned 0600 client key; in CI pq.yml exports those and
  the PQ-3 runner presents a client cert to the TLS-enforced DB.
- DB_SSLMODE default is verify-full only when ENVIRONMENT=production; dev/test
  default to prefer so existing non-TLS stacks/CI keep working. Override
